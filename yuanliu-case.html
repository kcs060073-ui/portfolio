SCENARIO / 使用场景

园区招商与信息流短视频制作：文案不断变化，素材需要按园区、内容语义与横竖屏方向反复查找和组合。

APPROACH / 产品思路

把文案拆分、选材、分镜和草稿生成连接起来；先搭好制作基础，再把画面判断与最终调整留给创作者。

OUTPUT / 交付形式

本机运行的图形工作台与命令行工具。输出剪映专业版草稿，后续配音、精剪、审看与成片导出在剪映中完成。

WORKFLOW / SECTION 01

把重复操作，变成连续流程

围绕一次真实的园区视频制作任务，将输入、选材、确认和草稿输出拆成四个清晰环节。

01 / INPUT

输入招商文案

准备脚本文本，选择园区、成片方向与制作风格，确定这条视频要表达的内容。

02 / MATCH

匹配本地素材

结合文案语义、园区和画面方向筛选候选视频或图片，减少逐个文件查找的重复操作。

03 / REVIEW

预览并调整分镜

按需要先查看分镜计划，预览候选画面并调整选择，再使用确认后的计划生成草稿。

04 / DRAFT

进入剪映继续创作

将画面、字幕及可用的音乐等组织为草稿，在剪映中检查、配音、调整与导出。

PRODUCT DECISIONS / SECTION 02

围绕实际制作设计

工具的价值落在日常使用中：内容输入方便，素材选择可检查，生成结果可继续编辑。

01 / 内容表达

语义选材与风格配置

将文案语义与素材规则结合，并提供“三连否”“招商”“没想到”三种基础风格配置，让不同表达方式有可复用的起点。

02 / 创作控制

先确认分镜，再生成草稿

预览并调整候选素材，把自动匹配与人工判断接在一起。生成的是可编辑草稿，为后续精剪留出空间。

03 / 重复任务

批量处理与任务回执

支持在工作台输入多条文案，批量推进任务，并通过回执查看结果；团队素材包可生成清单、校验并安装到本地素材库。

04 / 使用稳定性

保护已有草稿与素材

默认避免覆盖已有草稿，在素材库为空时拦截生成；将素材准备与环境检查放在输出之前，帮助使用者及时发现缺失项。

STATUS & REFLECTION / SECTION 03

让工具融入日常制作

这项实践展示了我将内容制作中的重复步骤拆成规则、界面与交付流程的尝试：理解任务，再把工具放进工作流。

当前形态：仓库已发布图形工作台、脚本、配置与模板，主要运行在 Windows 本机，需要使用者准备剪映专业版和本地素材。

使用边界：默认生成无配音草稿，音乐取决于本机可用素材。仓库记录了特定剪映版本的草稿读取兼容问题，实际输出仍需在目标版本中打开检查；macOS 的加密草稿兼容尚未完成。

后续关注：继续围绕素材匹配、草稿兼容与团队使用体验完善流程，以实际任务反馈判断改进效果。
